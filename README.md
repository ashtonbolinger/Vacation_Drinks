# Vacation Drinks

An interactive Ninja SLUSHi vacation drink dashboard with:

- 21 coffee, fruit slush, milkshake, and cocktail recipes
- Recipe filters and editable recipe details
- A selected-recipe grocery planner
- Copy-ready grocery summaries and persistent shopping checklists
- 1× and 2× batch planning
- Mobile-friendly and printable layouts

Open `index.html` directly or visit the GitHub Pages site for the hosted version.

## Important capacity note

The Ninja SLUSHi model has an 88-ounce vessel with a 64-ounce MAX FILL line. Most dashboard recipes use the 64-ounce max-fill batch; the Nutella Frappé is a smaller specialty batch.

## Data and privacy

The dashboard is a single self-contained HTML file. It uses no external dependencies, analytics, tracking, or remote storage. Recipe edits and grocery checkmarks are stored only in the current browser using local storage.
